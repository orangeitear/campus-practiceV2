- **问题2**：Git 操作不熟悉，feature/ai-config 分支与 dev 分支不一致，缺少 backend/、frontend/ 等目录
- **解决方案**：执行 `git merge origin/dev` 将 dev 最新代码合并到当前分支，同步目录结构

- **问题3**：合并时进入 Vim 编辑器，不知如何保存退出
- **解决方案**：按 `i` 进入插入模式输入提交信息 → 按 `ESC` → 输入 `:wq` → 按 `Enter` 保存退出
