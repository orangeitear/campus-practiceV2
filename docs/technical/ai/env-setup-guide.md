## 一、申请前准备

- 一个**阿里云账号**（可用支付宝/淘宝账号登录）
- 建议提前准备好**手机号**（需短信验证）

---

## 二、申请步骤

### 第1步：登录阿里云百炼平台

访问：https://dashscope.console.aliyun.com/

点击右上角 **「登录」**，使用阿里云/支付宝/淘宝账号登录。

### 第2步：进入控制台

登录后自动进入 **DashScope 控制台**。

### 第3步：创建 API Key

1. 在左侧菜单栏找到 **「API-KEY 管理」**
2. 点击 **「创建 API-KEY」** 按钮
3. 输入名称（如 `campus-qa`）
4. 点击 **「确定」**
