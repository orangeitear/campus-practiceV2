## 一、什么是向量库？

向量库（Vector Index）是 RAG 系统的核心组件。它存储了知识库中所有文档片段（chunk）的向量表示（Embedding），当用户提问时，系统通过计算相似度从向量库中检索最相关的文档片段。

本项目使用的是**预构建向量库**，基于河海大学官网公开信息构建，共包含 **354 个节点（chunk）**。
